# 服務紀錄系統 v1.2.0

## 本次更新
- 小幫手只能查看、修改及移至回收桶「自己建立」的服務紀錄。
- 老師建立的服務紀錄不會出現在小幫手畫面，Firestore 規則也會阻擋讀取。
- 個管老師可查看及管理自己名下全部紀錄，包含小幫手建立的內容。
- 服務紀錄列表與近期紀錄新增「建立者」欄位。
- 小幫手的操作紀錄只顯示自己的操作。

## 部署重點
1. 先將本資料夾全部檔案覆蓋到服務紀錄 GitHub Repository。
2. 到 Firebase Firestore Rules 貼上本版 `firestore.rules` 並發布。
3. 回入口網站執行一次「全部同步」。
4. 用老師與小幫手帳號各自測試。
