MUST 服務紀錄系統 v1.3.0 測試方式

一、一般測試
1. 將本資料夾檔案覆蓋到服務紀錄 GitHub Repository。
2. 等待 GitHub Pages 更新後按 Ctrl + F5。
3. 新增或修改學生，填寫：
   - 部別：日間部或進修部
   - 學制：例如四技
   - 科系：只輸入幼保（畫面會自動顯示幼保系）
   - 入學學年度：例如114
   - 班級：例如甲
4. 正常日期下應顯示：日四技幼保一甲。

二、提前模擬 2026/08/01
在原本服務紀錄網址後面加上：
?testDate=2026-08-01

例如：
https://f00931must-hash.github.io/must-service-record-system/?testDate=2026-08-01

此參數只會模擬「年級計算日期」，不會修改電腦時間，也不會修改 Firestore 資料。
114學年度入學的學生在模擬日期下應由一甲變成二甲。

測試完成後，移除網址後面的 ?testDate=2026-08-01，即恢復使用電腦／手機瀏覽器目前日期。

三、時間來源
年級不是使用 GitHub 伺服器時間，而是使用開啟網站的電腦或手機瀏覽器日期。
每次開啟學生列表、查看服務紀錄或下載 Excel 時，都會重新計算。
