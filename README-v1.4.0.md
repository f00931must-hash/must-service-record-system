# MUST Service Record System v1.4.0 學期管理版

## 更新內容
- 每筆服務紀錄新增「學年度」與「學期」。
- 新增紀錄時，系統會依日期自動帶入學年度與學期，仍可手動調整。
- 學生服務紀錄依學期分組，可展開／收合；目前學期預設展開。
- 舊紀錄若沒有學期欄位，會依日期自動歸類；沒有日期者列入「未分類」。
- 批次下載可指定學年度與學期，ZIP 檔名會包含學期。
- Excel 匯出基本資料增加學年度與學期。
- 左側選單固定，捲動內容時不會一起消失。

## 部署
直接將本資料夾完整內容上傳至原 GitHub Pages 專案即可。Firebase 規則不需因本次新增欄位而調整。
